# 访谈提纲网站

静态页面，无服务器、无自动答卷收集。仅发布空白页面，不上传访谈记录。

## GitHub Pages 发布

把此目录内全部文件上传到新建的公开仓库根目录（不是上传 ZIP 本身）。在仓库 Settings → Pages，选择 Deploy from a branch，分支 main、目录 / (root)，保存。等待 Pages 显示正式网站链接。

## 手机保存

填完点击“导出文字记录”，从浏览器下载列表找到 TXT。保存位置由手机浏览器设置决定。若下载不可用，点击“复制／查看记录”并全选复制到备忘录或微信。每位受访者结束后先保存并检查，再开始新访谈。浏览器草稿不跨设备同步。
